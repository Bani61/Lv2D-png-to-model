# 图层清单

出图或拆图前按这份清单准备素材。**图层名就是绑定规则**：名字对了，转头、眨眼、张嘴、头发摆动会自动接上；名字不在清单里的头部图层，只跟着脸转。

> **拆层粒度是可选的，缺口是不可选的。** 下面标"必须"的层没拆出来，模型就会出现具体缺陷（闭眼露白、张嘴毛刺、没有呆毛）；标"可选"的层缺了只是少一个表现。

---

## 一、通用要求

- 每个图层是一张和画布同尺寸的 RGBA PNG，彼此对齐，放在 `parts/`。
- `layout.json` 按从下到上的顺序列出图层：`name`、`texture`、`group`（`head` / `neck` / `body` / `pose`）、`visible`。
- `_L` 指画面左侧，`_R` 指画面右侧。
- 正面能看到的像素必须是原画。补画只用在原来被挡住、动起来会露出的地方。
- 每个图层只放这个部件自己的像素。不拿合成后的截图当贴图。
- 原画上的每条线都要落在某一层上。下巴线属于脸，不属于脖子。
- **一个部件只能出现在一层里。** 同一块皮肤同时画在两层，动起来会看到双层描边。

---

## 二、机器能拆到哪一步（重要）

AI 拆层（See-through / PSD2Live 自动拆分）**不是万能的**。下表是实测边界，标"人工"的必须由你拆，交给机器只会得到错误结果：

| 部件 | 自动拆层 | 说明 |
|---|---|---|
| 头发（后发 / 侧发 / 刘海） | ✅ 可以 | 大块形状，边界清楚 |
| **呆毛（单根翘发）** | ❌ **必须人工** | 太细，几像素宽，会被并进刘海或背景，拆出来常有断口。**机器做不到，得你自己加一层** |
| 脸皮、耳朵、脖子 | ✅ 可以 | |
| 眼白 / 瞳孔 / 上睫毛 | ✅ 可以 | |
| **上眼皮皮肤块 / 下眼皮皮肤块** | ⚠️ 半自动 | 常和脸皮粘在一起被拆成一块。需要人确认是否独立成层，见 [3.1](#31-眼睛必须拆到眼皮) |
| 嘴巴（整体） | ✅ 可以 | 但常拆成碎像素，见 [3.2](#32-嘴巴必须拆到牙-唇-口腔) |
| **上牙 / 下牙 / 上唇 / 下唇 / 口腔内部** | ❌ **必须人工** | 牙齿和舌头是开口内部的细小色块，自动拆分几乎必然把牙和口腔糊在一起 |
| 衣服、袖口、腰带 | ✅ 可以 | |
| 眼镜、耳环、挂坠 | ⚠️ 半自动 | 细框容易断，需要人补 |

**判断方法**：拆完后按 [3.2](#32-嘴巴必须拆到牙-唇-口腔) 逐条对照，缺哪一层就自己补，别指望重跑一遍能变对。

## 三、头部（group: head）

### 3.1 眼睛（必须拆到眼皮）

只拆"眼白 + 瞳孔 + 睫毛"是**不够**的。闭眼时上眼睑要往下压，如果眼睑下面没有皮肤层，压下去的地方会露出眼白或底色——这就是"闭眼露一条蓝线"的成因。

| 图层 | 内容 | 被挡住、要补画的部分 | 必须? |
|---|---|---|---|
| `Eye_Lid_Upper_L` `Eye_Lid_Upper_R` | **上眼皮皮肤块**：上睫毛上方到眉毛下缘之间的那块皮肤，含上眼窝的阴影 | 往上画到眉毛下面，和 `Face_Skin` 接缝处不留缝；闭眼时这块要能被压下来盖住眼白 | **必须** |
| `Eye_Lid_Lower_L` `Eye_Lid_Lower_R` | **下眼皮皮肤块**：下睫毛下方到颧骨之间那块皮肤 | 往下画到腮红区；笑眼时这块要能往上推 | **必须** |
| `Eye_White_L` `Eye_White_R` | 眼白，形状就是眼睛开口 | 不带睫毛；被眼皮挡住的边缘画完整 | 必须 |
| `Iris_L` `Iris_R` | 虹膜、瞳孔、高光 | 画完整的圆，被上下眼睑挡住的部分也要有 | 必须 |
| `Eye_Open_L` `Eye_Open_R` | 上睫毛 + 上眼睑那条线 | 不带眼白 | 必须 |
| `Eye_Lower_L` `Eye_Lower_R` | 下睫毛（可选） | | 可选 |
| `Eye_Crease_L` `Eye_Crease_R` | 双眼皮褶（可选） | | 可选 |
| `Eye_Closed_L` `Eye_Closed_R` | 闭眼的那条线，画在眼睛真正闭上的位置 | 不透出眼白 | 建议 |
| `Eye_Smile_L` `Eye_Smile_R` | 笑眼（可选） | | 可选 |
| `Eye_Open_Over_L` `Eye_Open_Over_R` | 压在头发上的睫毛尖（可选） | 睫毛整条在头发下面时留空 | 可选 |

**为什么眼皮必须单独成层**：闭眼不是"把眼睛缩成一条线"，而是"上眼皮从上面盖下来"。只有眼皮是独立图层，才能做出真实的闭眼；靠缩放眼白只能得到一个假的闭眼，且边缘一定毛。

### 3.2 嘴巴（必须拆到牙-唇-口腔）

一个 ` Mouth_Open` 层是**不够**的。张嘴时至少要能动上牙、下牙、上下唇和口腔内部，否则所有形变都压在一条描边上，必然出现尖角拉丝。

| 图层 | 内容 | 被挡住、要补画的部分 | 必须? |
|---|---|---|---|
| `Mouth_Teeth_Upper` | **上牙齿**：上排牙 + 上牙龈线 | 被上唇挡住的部分画完整；牙缝按原画 | **必须** |
| `Mouth_Teeth_Lower` | **下牙齿**：下排牙 + 下牙龈线 | 同上 | **必须** |
| `Mouth_Lip_Upper` | **上嘴唇**：上唇的形体与描边，含唇峰 | 张到最大时上唇没有的像素要补出来 | **必须** |
| `Mouth_Lip_Lower` | **下嘴唇**：下唇形体与描边 | 同上 | **必须** |
| `Mouth_Inner` | **口腔内部**：舌头、咽喉、上颚暗部，填满唇齿之间的洞 | 左嘴角、上下牙龈后面画到看不见为止，不能留透明 | **必须** |
| `Mouth_Open` | 张嘴的整体外轮廓（可选：用来给整组做形变包络） | 只有轮廓线也可，内侧由上面几层负责 | 可选 |
| `Mouth_Closed` | 闭嘴的唇线 | 只有线，不带一块肤色底 | 必须 |
| `Mouth_Skin_Upper` | **上唇上方皮肤块**：鼻底到上唇之间那块皮肤 | 上唇上抬时不能露背景；和 `Face_Skin`、`Nose` 接缝对齐 | **必须** |
| `Mouth_Skin_Lower` | **下唇下方皮肤块**：下唇到下巴之间那块皮肤 | 张嘴时下巴往下，这块皮肤要拉得动 | **必须** |
| `Mouth_O` `Mouth_Line` `Mouth_Frown` | O 型嘴、一字嘴、撇嘴（可选） | | 可选 |

**叠放顺序（从下到上）**：`Mouth_Inner` → `Mouth_Teeth_Lower` → `Mouth_Teeth_Upper` → `Mouth_Lip_Lower` → `Mouth_Lip_Upper` → `Mouth_Open`（如有）。

**命名说明**：`Mouth_Open`、`Mouth_Closed`、`Mouth_O` 这几个是绑定工具能识别的名字，会直接连到 `ParamMouthOpenY`。`Mouth_Teeth_*`、`Mouth_Lip_*`、`Mouth_Inner`、`Mouth_Skin_*` 是**本清单自定义**的名字：工具不会给它们单独做形变，它们跟着所在组的变形器走。所以：

- 拆分是为了**让你能在 Cubism 里单独修**（改牙齿位置、改口腔颜色），不是为了自动绑定；
- 如果你不打算进 Cubism 精修，把牙、唇、口腔**合并进 `Mouth_Open` 一层**反而更省事，但那样就没法单独修了。

### 3.3 头发（必须单独拆呆毛）

| 图层 | 内容 | 被挡住、要补画的部分 | 必须? |
|---|---|---|---|
| `Hair_Back` | 头后面的全部头发；长发连同垂在背后的部分 | 一直画到脸、耳朵、脖子后面：转头时脸边露出的是头发，不是背景 | 必须 |
| `Hair_Bang` | 刘海 | 不带额头阴影；发根画到头顶下面 | 必须 |
| `Hair_Side_L` `Hair_Side_R` | 脸两侧、耳朵前面的侧发（头发别在耳后时没有） | 发根往上画到刘海下面；里面不带耳朵和下巴线 | 必须 |
| **`Hair_Ahoge`** | **呆毛：头顶那根翘起来的单根头发，整根完整独立** | 根部要和 `Hair_Bang` / 头顶接上，**下面被它挡住的头发也要画满**——呆毛摆动时不能露出空洞 | **必须（人工）** |
| `Hair_Tail_L` `Hair_Tail_R` | 双马尾，从发绳往下 | 在 `Hair_Back` 上面；`Hair_Back` 沿交界往马尾里多画一点 | 可选 |
| `Hair_Bun` | 发髻、马尾等头顶的发团 | 和头顶接触的地方画到头发下面 | 可选 |

**呆毛为什么必须人工拆**：它通常只有 2–5 像素宽。自动拆层会把它当作刘海的一部分、或者当作背景里的一条杂线，拆出来的往往是有断口的碎片；而且**呆毛下面被挡住的头发，机器不会帮你补**。做法：

1. 在 PS 里用套索把它单独选中，剪切到新图层，命名 `Hair_Ahoge`；
2. 在原位置补画被呆毛挡住的头发（复制邻近头发纹理即可）；
3. 呆毛根部要多留 3–5 像素插进头发里，否则摆动时会脱开。

## 四、头部其余图层

| 图层 | 内容 | 被挡住、要补画的部分 |
|---|---|---|
| `Ear_L` `Ear_R` | 整只耳朵 | 被侧发挡住的部分 |
| `Face_Skin` | 脸皮和下巴轮廓线（不含眼皮块、不含嘴周皮肤块） | 刘海下的额头画到发际线；眼、眉、鼻、嘴下面是连续的皮肤，不留洞；刘海投在额头上的阴影画在这一层 |
| `Blush_L` `Blush_R` | 腮红（可选） | 不带脸的轮廓线 |
| `Brow_Neutral_L` `Brow_Neutral_R` | 眉毛 | 压在眉毛上的发丝画在刘海层，眉毛层里补完整 |
| `Brow_Angry_*` `Brow_Troubled_*` | 生气、困扰的眉毛（可选） | |
| `Nose` | 鼻子 | |
| `Glasses` | 眼镜（可选），只有镜框，镜片透明；在五官上面、头发下面 | 被头发挡住的镜腿画完整 |

## 五、脖子（group: neck）

| 图层 | 内容 | 被挡住、要补画的部分 |
|---|---|---|
| `Neck` | 脖子 | 上端画到下巴后面约脸高的八分之一，不带下巴线：转头时下巴从脖子前面滑过，后面要有脖子 |

## 六、身体（group: body）

名字不限，例如 `Chest`、`Body_Vest`、`Sleeve_L`、`Arm_R`、`Skirt`、`Belt`、`Bow`，从下到上排好即可。身体整体跟随左右转、前后倾、呼吸和倾斜。

**手臂层序**：`Arm_L` / `Arm_R` 要排在躯干图层**之后**（更靠上），否则袖子会被衣服盖住。这一条在清单里写死，因为自动绑定沿用 PSD 层序，PSD 错了模型就是错的。

---

## 七、挂件（group: body 或 head）

`Dangle_1`、`Dangle_2`……：项链吊坠之类绕上端摆动的小件，每件一层，放在它挂着的那一组最上面。底下的衣服要画完整：吊坠摆开时露出来。耳坠（`Dangle_Ear_1`、`Dangle_Ear_2`）在 head 组、脸皮上面，绕耳垂摆动。

---

## 八、手势（group: pose）

`Pose_Wave`、`Pose_Explain`、`Pose_Point`：做这个手势时脖子以下的整个身体，含两只手臂。手势打开时代替整个身体组，`visible` 设为 `false`。

---

## 九、命名对照（本清单 → 绑定工具识别名）

| 本清单 | 绑定工具识别的名字 | 连到哪个参数 |
|---|---|---|
| `Mouth_Open` | `张嘴` / `mouth_open` | `ParamMouthOpenY` |
| `Mouth_Closed` | `Mouth_Closed` | `ParamMouthOpenY`（0 端） |
| `Eye_Open_L/R` | `Eye_Open_L/R` | `ParamEyeLOpen/ROpen` |
| `Eye_Closed_L/R` | `Eye_Closed_L/R` | `ParamEyeLOpen/ROpen`（0 端） |
| `Eye_White_L/R` | `Eye_White_L/R` | 闭眼时联动 |
| `Iris_L/R` | `Iris_L/R` | 眼球跟随 |
| `Brow_*` | `Brow_*` | `ParamBrowLY/RY` |
| `Hair_Ahoge` | `Hair_Front` 或 `Hair_Ahoge` | `ParamHairFront` |
| `Mouth_Teeth_*` / `Mouth_Lip_*` / `Mouth_Inner` / `Mouth_Skin_*` / `Eye_Lid_*` | **无独立识别名**（跟随所在组变形器） | — |

名字不在识别表里的图层，不会被单独驱动，但会跟随所在组的变形器一起动。这是设计与预期行为，不是 bug。

## 十、交稿前自检

逐条打勾，缺一条就会在模型上看到对应缺陷：

- [ ] 眼睛有**上眼皮皮肤块**、**下眼皮皮肤块**各两层（左 + 右）
- [ ] 嘴巴有**上牙、下牙、上唇、下唇、口腔内部**五层
- [ ] 嘴巴有**上唇上方皮肤块**、**下唇下方皮肤块**各一层
- [ ] **呆毛**单独一层，且根部被挡住的头发已补画
- [ ] 手臂图层排在躯干之后
- [ ] 没有同一个部件出现在两层
- [ ] 每个图层都是同尺寸、对齐的 RGBA

任何一条做不到，就在提交时写清楚缺哪条——缺的层不会自动长出来，模型会带着对应缺陷出厂。
