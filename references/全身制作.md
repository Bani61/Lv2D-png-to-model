# 全身 Live2D 制作扩展

这份参考把“单图首版”扩展到全身。重点解决高精度拆层、上下身层级，以及 8 GB NVIDIA 显卡的本地拆层路径。

## 交付边界

- 半身可以走现有完整自动绑定流程。
- 全身首版可以先交付分层 PSD、深度、图层总览、静止合成和结构报告。
- 不要把“腿图层存在”当成“腿绑定完成”。腿部网格、脚底锁定、裤脚/裙摆遮挡和 VTS 实机动作必须单独验收。
- 原始立绘、失败拆层和每个模型候选都保留；清理只删临时缓存、损坏分片和无引用中间文件。

## 输入

推荐的全身 PSD 画布是 2048 × 3072（2:3），或保持原图更高分辨率。所有图层使用同一画布、透明背景和同一像素坐标：

- 正面或接近正面的站姿，双臂与身体分开，腿部轮廓可见。
- 衣服、皮肤和头发边界清楚；不要用零碎发丝横穿脸或关节。
- 关节重叠处多画 10–30 px：大腿压胯、小腿压大腿、裤脚压鞋口。
- 如果只有单张立绘，先确认完整人物和脚底都在画面内；缺脚、重度侧身或四肢大面积交叉时先补图，不要靠自动拆层硬救。

图层面板从上到下参考：

```text
前层配饰
头部前层：前发、眼镜、眉、眼、鼻嘴、脸皮、耳朵
上半身：衣服前片、腰部、左臂、右臂、躯干
下半身：腰带/胯部、左大腿、左小腿、左裤脚、左鞋
        右大腿、右小腿、右裤脚、右鞋、裤褶
脖子
后发
身体后层
```

标准名称见 [图层清单](图层清单.md)。

## 全身运动链

```text
全身根（腰/胯）
├─ 躯干
│  ├─ 脖子
│  │  └─ 头（脸、眼、发、眼镜）
│  ├─ 左肩 → 左上臂 → 左前臂 → 左手
│  └─ 右肩 → 右上臂 → 右前臂 → 右手
├─ 左腿
│  ├─ 左大腿 → 左膝 → 左小腿 → 左脚踝 → 左鞋
└─ 右腿
   ├─ 右大腿 → 右膝 → 右小腿 → 右脚踝 → 右鞋
```

实现要点：

- 旋转变形器负责四肢主旋转，轴心放在肩、肘、胯、膝、踝。
- 弯曲变形器负责关节内侧褶皱、裤脚、裙摆和躯干弯曲；网格三角形尽量规整，沿已有线稿布线。
- 全身外层用弯曲变形器做整体倾斜和呼吸；脚底在身体上下动作时保持不离开地面或固定基线。
- 衣物按前后遮挡拆成整块，不按颜色阈值把同一块布切成很多碎层。
- 全身转头仍使用正面小角度策略；大角度侧脸需要单独侧脸素材。

## 8 GB NVIDIA 本地拆层

适用环境：Windows、Python 3.12、RTX 5060 8 GB，程序、模型和缓存放在 D/F 盘。

推荐组件：

- ComfyUI
- ComfyUI-See-through 插件
- `24yearsold/seethroughv0.0.2_layerdiff3d_nf4`
- `24yearsold/seethroughv0.0.1_marigold_nf4`
- CUDA 版 PyTorch、torchvision、bitsandbytes、diffusers ≥ 0.37

8 GB 上按以下优先级：

1. 1280 × 1280，30 步，NF4。
2. `cache_tag_embeds=true`。
3. 深度层可用 720/768，再回放原分辨率。
4. 需要时启用 `group_offload=true`，速度会慢 2–3 倍。
5. 1536 只有在显存余量验证通过后使用，不以处理分辨率替代真实细节。

拆层前关闭浏览器、游戏、壁纸引擎和其他占 GPU 的程序。先记录 GPU、显存和 PyTorch CUDA 版本。

## 拆层质量门

拆层完成不等于可绑定。逐层检查：

- 每层只含自己的部件；头发层不含眼睛/皮肤，衣服层不含头发，鞋层不含裤脚，裤脚层不含脚踝。
- 原画可见像素可追回到对应层；隐藏面补画不覆盖正面原画。
- 在透明/中性背景和 VTS 粉底上分别检查边缘，避免白边、光晕和背景色残片。
- 检查脚踝、膝盖、腰胯、鬓角、下巴/领口、耳后和裤脚/鞋口。
- 深度排序必须稳定；近层不得随机穿插远层。
- 用同尺寸总览检查整张合成，再在 1:1 和 3–4 倍放大检查小部件。
- 对左右眼、手、腿、鞋保持角色自身左右约定，避免在 VTS 中反向绑定。

失败分类：

- 颜色正常但归属错误：修层或换种子，不做全图色差。
- 层边缘碎、空洞、背景混入：检查 See-through 原始层和深度，不用阈值反复抠。
- 腿/脚缺失或附着到衣物：优先换更清晰输入或提高分辨率；仍错则手工分层。
- 关闭某层后残留仍在另一层：先定位真实所有者，再修该层。

同一个症状用同一种方法失败两次后，改用不同数据路径，不继续微调同一个阈值。

## See-through 输出检查

本机插件应输出语义 RGBA 图层、逐层深度、合成预览，以及 PSD 或可重新打包的图层目录。

交付前保留：

- 原图哈希
- 模型版本和权重校验值
- 分辨率、步数、种子、NF4/offload 设置
- 图层总览
- 静止合成
- 合成与原始立绘的并排图
