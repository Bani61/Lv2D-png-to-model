# 全身 Live2D 自动流水线预案

目标：从正面、正比、全身、双手自然下垂的 `001.png`，制作动作幅度尽量高、可进 VTube Studio 的全身皮套。优先级是分层正确性、全身关节连续性、衣鞋所有权，其次才是自动化速度。

## 不妥协的全身质量门

### G0：源图和变体

- 身体正立，脸部尽量正面；头顶、下巴、肩、肘、腕、胯、膝、踝、脚尖全部可辨认。
- 双臂与躯干之间至少留出可拆轮廓；手指、袖口、裙摆/裤脚、鞋面不要糊成同一色块。
- 至少准备中性图、闭眼、笑眼、张嘴/口型差分；大幅挥手若需要，必须生成手臂抬起后的整图差分，不能靠把下垂手臂硬旋上去。
- 对遮挡区域补全要有单独素材：腋下、后发下方脸、袖内、裙内、双腿交叠处。不能把“没画到的区域”当作可由网格变出来。

### G1：拆层

- See-through 输出必须逐层检查，不只看总预览：
  - 左右以角色自身为准；角色左通常显示在画面右。
  - 腿、鞋、手、左右眼不能互相粘层。
  - 发前/发后、脸、耳、眼镜、耳饰、上衣、下装各有正确层级和深度顺序。
  - 被完全遮住的发丝/衣角至少要检查是否需要补绘；See-through 不会自动补全一切。
- 重新合成后，中性态不能缺少原画可见像素；边缘只允许 See-through 自身的轻微软化。
- 若腿或手臂在一层内：先用 PSD2Live 网格拆分/组件拆分，再检查关节两侧是否有足够像素和余量。不能只用一条水平线硬切。
- 旧版失败结果永久保留，不覆盖；新结果进独立版本目录。

### G2：绑定

- 头部：`ParamAngleX`, `ParamAngleY`, `ParamAngleZ`, 眼/眉/嘴/耳。
- 身体：`ParamBodyAngleX/Y/Z`, `ParamBodyLean`, `ParamProportion`, 呼吸。
- 肢体：左右肩、上臂、前臂、手；左右髋、大腿、小腿、脚。骨架只作为生成工具，最终必须烘成 Cubism 原生变形器/关键形/物理。
- 头发/衣服：根固定、尾摆动；长发、裙摆、袖口和挂件分别验收。

### G3：导出和运行

- 先存 `.psd2live`，再出 `.cmo3` 检查层级和关键形，随后出 `.moc3` 文件族。
- Cubism Editor 里检查 9 个头姿态、身体极限、左右手抬起、双膝弯曲、脚底和鞋底。
- VTube Studio 中检查面捕、眨眼、口型、呼吸、头发物理、左右转头和全身取景。
- 导出损失报告必须读完；纹理精度、混合模式、动作/物理降级不能忽略。

## 推荐流水线

1. **立绘规范化**：建立 `A0-base`，生成眼口与手势差分。所有差分与原图共用画布、机位和角色比例。
2. **高质量拆层**：
   - 首选 Hugging Face 1280 或 ModelScope 1536。
   - 本机 8 GB 仅在用户明确要求时运行；NF4 1280/30 曾超过 50 分钟未完成，不适合反复试错。
   - 本地低显存先做 768/15 只用于流程验证；正式全身不要用该分辨率直接当最终交付。
   - 已安装 `tackcrypto1031/tk_seethrough` 时，可以用 `scripts/make_tk_workflow.py` 生成 API 工作流；默认关闭 `auto_fill`，开启前确认最多 5 轮的推理成本。
   - tk 的 `auto_fill` 只修复缺层和低相似度，不能用作帽檐、衣领顺序的最终判断。
3. **PSD 规范化**：建立稳定命名与层级树。建议：

```text
Root
├─ Back
│  ├─ back_hair
│  ├─ back_accessories
│  └─ tail_wings
├─ Body
│  ├─ bottomwear
│  ├─ legwear_L
│  ├─ legwear_R
│  ├─ footwear_L
│  ├─ footwear_R
│  ├─ topwear
│  ├─ neckwear
│  └─ neck
├─ Arms
│  ├─ arm_L
│  ├─ hand_L
│  ├─ arm_R
│  └─ hand_R
├─ Head
│  ├─ face
│  ├─ ears
│  ├─ eye_close
│  ├─ eyewhite_L/R
│  ├─ irides_L/R
│  ├─ eyelash_L/R
│  ├─ eyebrow_L/R
│  ├─ nose
│  ├─ mouth
│  └─ eyewear
└─ Front
   ├─ side_hair_L/R
   ├─ front_hair
   ├─ headwear
   └─ earwear
```

4. **导入 PSD2Live**：
   - 使用 Windows 便携版，安装/解压到 `D:\Live2D-Fullbody`。
   - 选择“完整”预设。
   - 先看图层识别表，再生成；错标必须在生成前修正。
   - 衣领、头发和配饰的穿插优先使用 `source_split_depth`：源网格放衣领，`middle_ids` 放脖子，名称为后层、前层。
   - `source_split_depth` 会取代原源图层，只有撤销能恢复，因此先保存工程。
5. **MCP 精修**：
   - `workspace_overview` → `workspace_inspect`。
   - 调父级、绘制顺序、遮挡、网格和物理。
   - 每轮修改先 `workspace_preview_edits`，再 `workspace_apply_edits`。
6. **Cubism/VTS 导出**：
   - `.cmo3` 用于人工检查。
   - `.moc3 + model3.json + physics3 + motions + textures` 用于运行。
   - `.vtube.json` 用于参数映射和热键。
7. **AutoLive2d 可选**：仅用于快速面捕、OBS 或动作风格预览；不接管最终 Cubism 资产。

## 8 GB 本机配置

- 已有环境：`D:\Live2D-Fullbody`
- 模型缓存：`D:\Live2D-Fullbody\models\huggingface`
- ComfyUI：`D:\Live2D-Fullbody\tools\ComfyUI`
- 下载脚本：`F:\半白bani_\live 2D\tools\download_seethrough_nf4.ps1`
- 推理入口：`F:\半白bani_\live 2D\tools\run_seethrough_api.ps1`
- 本机固定参数：
  - `quant_mode=nf4`
  - `group_offload=false`；此机器开启会崩溃
  - 预览：768 或 1024，15 步
  - 正式：1280，30 步，但预计耗时长，必须单独预约
- 运行前后都要查显存；超过 7.9 GB 后发生 OOM 不应靠重复重试解决。

## 自动化边界

- 不自动启动耗时拆图：先确认网络源、分辨率、步数、预计时长和是否允许上传立绘。
- 不自动覆盖旧模型或旧失败版本。
- 不把固定网格、六参数线性叠加当作“高灵活性全身绑定”。
- 不声称 PSD2Live 自动结果已是成品；导出前必须看见九头姿态、手臂、腿部、脚底和衣物极限测试。
- 三层修复仍未解决同一症状时停止调代码，回到分层/补绘素材。

## 下一步建议

1. 在 D 盘安装 PSD2Live 便携版。
2. 用现有 `001.png` 生成标准化全身 PSD；优先云端 1536，完成后再继续。
3. 在 PSD2Live 中运行完整预设并检查 G1/G2。
4. 根据检查结果决定重拆、补绘或进入 Cubism 精修。
5. 只有用户明确批准后才启动下一轮本地推理。
