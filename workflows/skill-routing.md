# 技能选型：三个 skill 什么时候用哪个

手上有 DSH 环境时，Live2D 相关的技能有三个，别选错：

| 技能 | 擅长 | 不擅长 |
| --- | --- | --- |
| `lv2d-png-to-model`（本仓库） | 立绘拆层、PSD 结构检查、PSD2Live 绑定导出、缺陷排查 | 半身精细绑定、代码级网格控制 |
| `live2d-pipeline` | 全流程编排：出图 → See-through 拆层 → PSD2Live → 绑定 → 验收 | 单独修某个图层的绑定细节 |
| `live2d-halfbody` | 半身皮套，从立绘或纯文字描述生成，内置 rigkit | 全身、物理 |

## 一个判定问题

> **你手上有没有已经分好层的 PSD？**

- **有 PSD，想让它动起来** → 本仓库。走 `workflows/psd2live-mcp.md`。
- **没有 PSD，只有一张图或一段描述** → `live2d-pipeline`（先生成/拆层），或 `live2d-halfbody`（半身、要精细绑定）。
- **已有模型，只想改某处** → 本仓库的 MCP 部分（`workflows/psd2live-mcp.md`）。

## 硬规则

1. 只做半身时别用 PSD2Live 全套，`rigkit` 的质量更好、可控性更强。
2. 做全身时别用 `rigkit.prepare/build` 冒充可靠绑定——它不负责全身骨骼和物理。
3. 拆层质量和绑定质量是两件事。拆层错了，绑定越自动结果越糟。
4. 任何"自动"结果都要渲染核对。三个技能都不保证一次就对。
5. 交付前保留上一版目录，别覆盖。
6. 不要为了省事把 A 技能的输出当 B 技能的输入格式用（`.cmo3` 不能喂给拆层）。

## 互相转交

| 从 | 到 | 触发条件 |
| --- | --- | --- |
| pipeline | 本仓库 | PSD 已经拆好，需要绑定或修绑定 |
| 本仓库 | halfbody | 用户改主意，只要半身 |
| halfbody | 本仓库 | 用户要全身，或要物理摆动 |
| 任意 | Cubism 手工 | 需要 `±30°` 以上的转头质量，自动绑定做不到 |

## 本机能力现状（记录用）

- PSD2Live 3.6.7：可用，MCP 通。
- Cubism Editor 5.3.02：可用，但**没有外部应用集成 API**（端口 22033 不通），5.4 alpha 已于 2026-10-18 停止发放且带时间锁，故 Cubism 的自动化编辑在当前机器上不可用。
- VTube Studio：可用；面捕需要摄像头与 Webcam DLC 状态正常。
